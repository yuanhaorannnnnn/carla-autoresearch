# CARLA Agent branding

Original community-project identity. The open observation frame and orange registration point represent bounded operations and capture. These assets do not use official CARLA, NVIDIA or OpenAI logos and do not imply affiliation.

| File | Size | Use |
|---|---|---|
| `icon.png` | 1024 × 1024 | Primary repository/plugin icon |
| `icon-512.png` | 512 × 512 | Smaller distribution copy |
| `hero.png` | 1800 × 600 | README masthead |

All images have an opaque midnight background. Keep the complete square icon; do not remove its background automatically. Use `CARLA Agent` as the banner alt text. The visible name must also exist as real README text.

Palette: midnight ink `#10252E`, warm ivory `#F4F1E8`, registration orange `#F36E3A`. These are direction targets; generated pixels contain antialiasing and small tonal variation.

Created using the built-in image generation tool, then scaled with FFmpeg. The icon and banner are branding illustrations, not simulator screenshots or runtime evidence.
