# 安装与真实使用演示计划

状态：**已记录，暂缓执行**。2026-11-02 决定先更新 GitHub 展示、文档与图标；以下是后续验收流程，不是已完成的安装指南或运行证明。

目标：从干净环境安装插件和工具，在新的会话中发现正确 skill，连接实际 CARLA，交付可查看的采集结果和可追溯实验记录。

## 演示步骤

1. **准备版本。** 在正式主线完成集成后，标明插件与 Python 工具的版本、commit 和文件摘要。安装材料不含个人路径、开发缓存或本地运行记录；不为此重新编译 CARLA。
2. **干净安装。** 使用独立 Python 虚拟环境和演示目录，不设置开发用 PYTHONPATH、不采用 editable install。通过本地 marketplace 安装插件，工具安装到独立环境；核对宿主实际读取的缓存副本、版本和依赖路径。
3. **新会话引导。** 从“连接 CARLA，查看当前地图与传感器”开始，检查 skill 发现、工具定位、profile 创建，以及 CARLA PythonAPI 与服务端版本匹配。插件安装与本机工具/PythonAPI 配置分别验收。
4. **真实操作。** 使用已有 CARLA 包和专用实例，执行短 RGB 采集，展示原始图像、帧号、仿真时间、完整配置与输出位置；确认只清理自有对象，并在身份匹配时恢复 settings。
5. **有限研究。** 预先确定 LiDAR 变化项、质量底线、比较阈值与预算。展示计划校验、配对试验、独立确认、状态和只读比较；失败或没有改善照实保留，不用模拟结果替代真实运行。
6. **移除安装。** 移除演示插件与专用工具环境，确认既有插件、原仓修改和 CARLA 环境未受影响。采集与研究产物保留在独立输出目录。

## 判断标准

| 层次 | 需要看到的证据 |
|---|---|
| 插件安装 | 宿主中可发现/启用，版本与安装副本对应；完整 skills/reference 可读取 |
| 工具安装 | 离开源码目录仍能调用，依赖来自新环境，没有隐式借用开发路径 |
| 操作 | 实际 server 响应、原始图像/点云、frame/timestamp、清理与恢复记录 |
| 研究 | 冻结输入、真实 trial 产物、失败记录、比较与独立确认的适用范围 |
| 移除 | 演示安装已移除，既有环境和成果仍保留 |

若使用的 CARLA 二进制没有可追溯源码 commit，只报告该二进制上的运行结果，不称作 sprint42 构建验收。107 项 skill 指引和 17 个基础 operation 的存在，不代表所有原生/条件能力均已实机验证。

当前根目录 `plugin.json` 使用 portable Agent Plugins 格式；`.codex-plugin/plugin.json` 是兼容布局，不因 Stroll 使用兼容布局而强制迁回。正式安装流程应按执行时的宿主支持核验，参见 [官方插件打包文档](https://developers.openai.com/plugins/build/plugins)。
