# Planning Rules

## Purpose

Define where planning artifacts live and how `/plan` and planning files split
responsibility.

## Default Location

Use `.planning/conversations/<conversation-id>/`.

## Default Writes

- `/plan` → `.planning/conversations/<conversation-id>/spec.md`
- planning files → `.planning/conversations/<conversation-id>/task_plan.md`
- planning files → `.planning/conversations/<conversation-id>/findings.md`
- planning files → `.planning/conversations/<conversation-id>/progress.md`
