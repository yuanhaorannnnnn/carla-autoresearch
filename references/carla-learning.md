# 入门教学与预测实验

只在用户要学习、引导上手或理解实验时读。普通查询不套完整教程。

从用户当前问题选一个可观察结果：连接信息、世界 snapshot、某个 blueprint 属性或一小段授权采集。先执行获得实际输出，展示一个短片段并解释每个与问题有关的值，标明读取时间与适用 server。不要将文档示例、假客户端输出或预期值伪装成现场结果。

把下一步变成可检验预测，而非命令清单。例如已有独占实验授权时，先记录实际 frame/time，解释 `fixed_delta_seconds`，请用户预测推进 2 帧后 frame 与 simulation time 如何变化；在同一 session 有界 tick，比较前后输出。用户没有授权推进时，只展示预测和待执行条件，继续只读。地图/episode 改变、其他 client tick 或观测不匹配时，保留差异并核对条件，不强行给出“2 × 步长”的成功结论。

传感器入门可先读真实属性，解释 sensor rate 与世界步长的关系；采集后展示原始 manifest 中实际 frame/timestamp 和数据路径。选已有结果里真实存在的失败/边界对照（如缺 blueprint、版本不匹配、超时）；没有失败样本时说明边界，不能伪造一次失败或扩大实验制造反例。

每轮只增加能回答当前问题的实验。用户的预测、解释或自行复现是学习反馈；命令退出 0 只证明该命令完成。若用户尚未反馈，写“已演示，理解/独立复现待确认”，不写“已掌握”。
